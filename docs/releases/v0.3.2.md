# PadBridge 0.3.2

Windows 安装器现在一次完成主程序、USB 通信组件和扩展屏幕组件的配置。
新用户只需下载并运行一个 EXE，安装完成后可直接选择 USB / Wi-Fi、镜像 / 扩展。
iPad 仍需打开 OpenDisplay；首次 USB 连接需在 iPad 上信任电脑。

## 下载

| 文件 | 用途 |
| --- | --- |
| `padbridge-0.3.2-windows-x64-setup.exe` | Windows 11 x64 完整安装，推荐 |
| `padbridge-0.3.2-windows-x64.zip` | 便携版，适合已经配置组件的电脑 |

## 一次安装

- 自动检测 Apple USB 服务与程序拥有的虚拟显示驱动；已有可用组件直接复用。
- 缺少 USB 支持时，向导自动从 Apple 官方服务器获取 Apple Mobile Device Support
  19.4.0.10 x64（约 39 MB），验证 SHA-256 和 Apple 发布者签名后安装。不要求用户安装
  iTunes、Apple Devices、Python、包管理器或另外运行命令。
- Virtual Display Driver 25.7.23 的签名驱动已内置，保留 MIT 许可证，安装时再次验证签名。
- 首次安装缺失系统组件需要联网及管理员确认，Windows 也可能要求确认驱动发布者。
  Apple 的原始许可条款与 PadBridge 许可一起显示在安装向导中。
- 组件准备失败时停在安装页，显示错误并允许重试；不会把未完成的 USB / 扩展配置报告为成功。
  需要重启时由安装器提示，不强制重启电脑。
- 升级沿用用户安装目录和设置。系统组件供多个程序共用，卸载主程序不会移除它们。
- 保留其他软件的虚拟显示配置，遇到无法确认所有权的同类驱动时报告冲突。

## 仓库与包整理

- 移除两份过时 Linux 交接文档和四个未使用的上游界面 / 入口模块；仍可从 Git 历史查阅。
- Windows 包把完整对应源码集中为 `source.zip`，仅收集 Git 跟踪文件，避免打入本机临时文件。
- 安装目录仅附 Windows 指南、当前发布说明与许可证；完整开发文档、构建脚本、两端代码和测试
  仍在源码包内。Ubuntu 运行功能保持 v0.3.1 的行为。

安装器本身尚未做 Authenticode 代码签名；内置显示驱动和下载的 Apple 组件各自有独立签名。
