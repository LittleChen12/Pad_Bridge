# PadBridge 0.3.1

Windows 11 新增可直接下载安装的 EXE，安装后可从开始菜单启动，也可在
“设置 → 应用 → 已安装的应用”中卸载。保留 v0.3.0 的 Windows 与 Linux 串流功能。

## 下载

| 文件 | 用途 |
| --- | --- |
| `padbridge-0.3.1-windows-x64-setup.exe` | Windows 11 x64 安装版，推荐普通用户下载 |
| `padbridge-0.3.1-windows-x64.zip` | Windows 便携版，完整解压后运行 |
| `padbridge_0.3.1_amd64.deb` | Ubuntu 24.04 amd64 / Xorg 安装包 |
| `padbridge-0.3.1-source.tar.gz` | 对应版本标签的源码 |
| `SHA256SUMS`、`SHA256SUMS-windows` | 下载文件的 SHA-256 校验值 |

## Windows 安装与升级

- 安装向导支持简体中文和英文，默认安装到当前用户的 `%LOCALAPPDATA%\Programs\PadBridge`，
  应用安装本身不要求管理员权限；自动创建开始菜单入口，可选创建桌面快捷方式。
- 安装包包含 Python、Qt、视频运行库和完整项目源码，无需用户另外安装 Python 或手动处理 `_internal`。
- 后续运行新版安装包即可升级，沿用原安装目录，保留 AppData 中的连接、画面和左右位置设置。
- 更新和卸载前，从托盘或窗口菜单选择“退出 PadBridge”。检测到界面或后台进程仍在运行时，
  安装器会要求先退出，不会强制结束正在使用的串流。
- 卸载移除已安装的程序文件和快捷方式，保留用户设置与用户自行放入安装目录的其他文件。
  Apple 通信组件、独立安装的虚拟显示驱动和显卡程序配置不随应用卸载。
- 原有 ZIP 用户可直接改用安装版，用户设置仍然共用；旧便携目录由用户自行保留或移除。
  显卡按 EXE 路径保存的设置需指向新的安装位置，详见 Windows 指南。

应用安装器目前未做 Authenticode 代码签名，Windows 可能显示未知发布者；
这与首次扩展时单独安装、已签名的虚拟显示驱动是两回事。安装器不自动安装驱动或更改安全策略。

## 验证

Windows CI 增加真实安装、旧版本安装记录升级、开始菜单和卸载登记、运行中保护、
卸载后保留用户文件与设置的回归测试，并验证安装后的编码器。
Ubuntu 继续执行原有测试、`.deb` 构建与包检查。本版没有调整 Linux 串流管线或性能参数。

完整使用说明见 [Windows 指南](https://github.com/LittleChen12/Pad_Bridge/blob/v0.3.1/docs/windows.md)。
