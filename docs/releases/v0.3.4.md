# PadBridge 0.3.4

Windows 画面设置只保留一个“目标帧率”：用户设多少，就按多少发送。

- 可选 15～120 FPS，默认 60。设置 120 后，即使 OpenDisplay 声明 60 FPS，仍使用 120
  的采集节奏、编码时间基准和视频配置，不自动改成 60。
- 移除额外的帧率开关、实验性文案和模式标签；已有 120 FPS 设置在升级后继续生效。
- 自建副屏同步选择 60/90/120 Hz，镜像保持电脑主屏刷新率。接收端尺寸与像素吞吐限制
  仍通过视频缩放处理，不降低用户选定的目标帧率。
- 状态卡显示目标与实际发送 FPS。实际吞吐受电脑性能、连接状况影响，屏幕物理刷新率
  由 iPad 决定。
- 包含 0.3.3 的普通权限保存修复：新配置继承个人 AppData 权限；旧版管理员创建的配置
  只需一次权限修复，日常启动和修改设置不必使用管理员权限。
- Windows 安装器继续一次配置主程序、USB 与扩展组件，升级保留个人设置。

命令行示例：

```powershell
PadBridge.exe start --transport usb --display-mode extend --monitor auto --fps 120
```

Windows 安装包为 `padbridge-0.3.4-windows-x64-setup.exe`。
Ubuntu 图形界面及其接收端协商行为保持不变。
