# PadBridge 0.2.0

首个发布版本：通过 USB 或同一局域网 Wi-Fi，将 iPad 用作 Ubuntu 扩展屏或镜像屏。
iPad 端使用 App Store 的 OpenDisplay（Philip Poloczek）。

## 功能

- 扩展屏与保持主屏原始设置的镜像模式。
- 分辨率、15～60 FPS、自动或 1～50 Mbps 目标码率。
- NVENC 硬件编码，无法使用时尝试 x264 软件编码。
- 侧边栏界面和系统托盘：关闭窗口后继续连接，托盘退出则停止串流并回收副屏。
- 未连接时不启动视频采集或编码。
- 修复显示尺寸变化时的 XShm BadMatch 竞争，以及镜像切回扩展后等待鼠标移动才更新显示区域的问题。

## 安装

支持目标为 **Ubuntu 24.04 amd64 / Xorg**。Windows、Wayland 和 ARM 尚不支持。

```bash
sudo apt install ./padbridge_0.2.0_amd64.deb
```

扩展模式需要 Intel / AMD 驱动支持的空闲 HDMI 接口；镜像模式不需要创建虚拟接口。
**镜像请在 PadBridge 内切换，系统显示设置中的强制镜像不是支持路径。**
Wi-Fi 协议适用于可信局域网。

## 验证与文件

- 发布前通过 26 项本地测试和 143 项上游协议 / 会话测试。
- 实机验证过 USB、Wi-Fi、镜像与扩展、参数调整及活动连接中的托盘退出。
- 使用独立 Xephyr 显示器验证截图尺寸变化后的恢复；不以 CI 通过代替硬件验证。
- 其他电脑的显示接口、驱动和性能尚未逐一实测。

下载 `.deb` 安装包、`padbridge-0.2.0-source.tar.gz` 对应源码及 `SHA256SUMS`。
发布包使用系统依赖，不包含开发机的运行库、用户配置或测试截图。
